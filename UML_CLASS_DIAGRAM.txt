╔════════════════════════════════════════════════════════════════════════════════╗
║                          RELATIONSHIP MATRIX                                   ║
╠════════════════════════════════════════════════════════════════════════════════╣
║                                                                                ║
║  User ──initiates──► Order                                        (1 User : N Orders)
║         One customer can place multiple orders                     Cardinality: 1:N
║                                                                                ║
║  Restaurant ──fulfills──► Order                                  (1 Restaurant : N Orders)
║         One restaurant can fulfill multiple orders                 Cardinality: 1:N
║                                                                                ║
║  Driver ──delivers──► Order                                      (1 Driver : N Orders)
║         One driver can deliver multiple orders                     Cardinality: 1:N (0..1 optional)
║                                                                                ║
║  Order ──contains──► MenuItem                                    (N Orders : N Items)
║         An order can contain multiple items                        Cardinality: N:N
║                                                                                ║
║  Restaurant ──manages──► MenuItem                                (1 Restaurant : N Items)
║         A restaurant manages its menu items                        Cardinality: 1:N
║         Supports filtering by category (Drinks, Desserts, etc.)                ║
║                                                                                ║
╚════════════════════════════════════════════════════════════════════════════════╝


╔════════════════════════════════════════════════════════════════════════════════╗
║                         CLASS RESPONSIBILITIES                                 ║
╠════════════════════════════════════════════════════════════════════════════════╣
║                                                                                ║
║  USER (Customer)                                                               ║
║  ├─ Manage customer identity (name, contact info)                              ║
║  ├─ Store saved addresses and payment methods                                  ║
║  ├─ Maintain purchase history for verification                                 ║
║  └─ Determine if user is a "real user" (has purchase history)                  ║
║                                                                                ║
║  RESTAURANT (Vendor)                                                           ║
║  ├─ Manage restaurant details (name, address, hours)                           ║
║  ├─ Build and maintain menu catalog                                            ║
║  ├─ Add/remove menu items                                                      ║
║  └─ Filter items by category (Drinks, Desserts, Burgers, etc.)                ║
║                                                                                ║
║  ORDER (Transaction)                                                           ║
║  ├─ Link user, restaurant, and driver                                          ║
║  ├─ Store selected items from menu                                             ║
║  ├─ Automatically calculate total cost                                         ║
║  ├─ Track order status (Placed → Preparing → Delivering → Completed)           ║
║  └─ Provide order summary information                                          ║
║                                                                                ║
║  DRIVER (Courier)                                                              ║
║  ├─ Store driver identity (name, vehicle type)                                 ║
║  ├─ Track current location for delivery                                        ║
║  ├─ Manage availability status                                                 ║
║  ├─ Accept and complete deliveries                                             ║
║  └─ Maintain list of active deliveries                                         ║
║                                                                                ║

║                              USAGE EXAMPLE                                     ║
╠════════════════════════════════════════════════════════════════════════════════╣
║                                                                                ║
║  # Create restaurant and menu                                                  ║
║  restaurant = Restaurant("Spicy Delights", "123 Main St")                      ║
║  restaurant.add_menu_item(MenuItem("Spicy Burger", 12.99, "Burgers", 4.8))     ║
║  restaurant.add_menu_item(MenuItem("Large Soda", 3.49, "Drinks", 4.5))         ║
║                                                                                ║
║  # Create user and order                                                       ║
║  user = User("John Doe", "555-0123")                                           ║
║  order = Order(user, restaurant)                                               ║
║  order.add_item(restaurant.menu_items[0])  # Add Spicy Burger                 ║
║  order.add_item(restaurant.menu_items[1])  # Add Large Soda                   ║
║                                                                                ║
║  # Assign driver and process                                                   ║
║  driver = Driver("Alice Smith", "Car")                                         ║
║  order.assign_driver(driver)                                                   ║
║  order.update_status("PREPARING")                                              ║
║  order.update_status("DELIVERING")                                             ║
║  order.update_status("COMPLETED")                                              ║
║                                                                                ║
║  # Verify real user                                                            ║
